# Hardware

Physical designs for the final product. **Nothing here yet** — scaffold;
files land as they're made in Phases 3–5.

- `pcb/` — KiCad projects: round LED plate (aluminum-core MCPCB) + round
  FR4 controller (ESP32-MINI-1, buck regulator, 5× AO3400A MOSFETs)
- `bulb/` — shell integration: potted HLK AC-DC module, E26/E27 screw base,
  diffuser dome, thermal bonding
- `remote/` — handheld enclosure + mounting for XIAO board, mic, button,
  battery (Phase 6)
- `bom/` — per-phase bills of materials
